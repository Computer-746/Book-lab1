Chapter 3: Computer Software and Operating System

Concept of Computer Software

In simple terms, computer software is a set of instructions, data, or programs used to operate computers and execute specific tasks. It is the non-physical component of a computer system, in contrast to hardware, which is the physical component. Without software, hardware is just a collection of inert electronic components; it cannot perform any useful work. Software acts as an intermediary between the user and the computer hardware, translating user commands into a language the hardware understands and then presenting the results back to the user.

Key Characteristics of Software

It is developed or engineered, not manufactured in the traditional sense.

It does not wear out over time like hardware; however, it can deteriorate due to bugs or outdated technology.

Most software is custom-built rather than assembled from existing components.

Types of Software

Software can be broadly categorized into three main types.

1. System Software

System software is a type of computer program that is designed to run a computer's hardware and application programs. It provides a platform for other software to run on. It is the most essential type of software, as it manages and controls the computer's internal operations.

Examples of System Software

Operating Systems (OS):
Manages all computer hardware and software resources. Examples include Microsoft Windows, macOS, Linux, Android, and iOS.

Device Drivers:
Programs that control a particular type of device attached to your computer, such as a printer, scanner, or webcam.

Firmware:
Permanent software programmed into read-only memory (ROM), such as BIOS in computers or software embedded in routers.

Utility Software:
Designed to help analyze, configure, optimize, or maintain a computer.

2. Application Software

Application software, also known as an application or "app," is a computer program designed to perform a specific task or set of tasks for the end-user. Unlike system software, application software does not manage the computer's internal operations; instead, it focuses on user-oriented tasks.

Examples of Application Software Commonly Used by Students in Nepal

Word Processors:
Microsoft Word, Google Docs, LibreOffice Writer.

Spreadsheet Software:
Microsoft Excel, Google Sheets, LibreOffice Calc.

Presentation Software:
Microsoft PowerPoint, Google Slides, LibreOffice Impress.

Web Browsers:
Google Chrome, Mozilla Firefox, Microsoft Edge.

Multimedia Software:
VLC Media Player, Adobe Photoshop for image editing.

Educational Software:
Programs designed for learning specific subjects or skills.

3. Utility Software

Utility software is system software designed to help analyze, configure, optimize, or maintain a computer. It performs tasks necessary for the smooth functioning of the computer system but is not directly involved in the core operations managed by the operating system.

Examples of Utility Software

Antivirus Software:
Protects the computer from viruses, malware, and other threats.

Disk Defragmenters:
Reorganize fragmented data on a hard drive.

Disk Cleaners:
Remove unnecessary files from the hard drive.

Backup Utilities:
Create copies of files for recovery.

Compression Utilities:
WinRAR and 7-Zip.

File Managers:
Windows File Explorer.

Concept of Operating System (OS)

An Operating System (OS) is the most important system software that manages computer hardware and software resources. It acts as an interface between the user and the computer hardware. Every computer, from a smartphone to a supercomputer, must have an operating system to run other programs. The OS is responsible for managing memory, processes, and all of its software and hardware.

When you power on your computer, the operating system is the first software to load and it remains in memory until the computer is turned off. It provides a consistent environment for application software to run and for users to interact with the computer.

Functions of Operating System

1. Process Management
   Manages running programs, allocates CPU time, creates and terminates processes, and schedules tasks.

2. Memory Management
   Allocates and deallocates memory while protecting programs from accessing each other's memory.

3. File Management
   Organizes, creates, deletes, copies, moves, and retrieves files.

4. Device Management
   Controls printers, scanners, keyboards, monitors, and other I/O devices.

5. Security
   Provides password protection, access control, and protection against malicious software.

6. Error Handling
   Detects hardware failures, software errors, and power failures.

7. User Interface
   Provides either Command Line Interface (CLI) or Graphical User Interface (GUI).

Types of Operating Systems

Single-user Operating System

Designed to be used by a single user at a time. It focuses on providing a good experience for one user while managing resources primarily for that user's applications.

Examples:
MS-DOS
Windows 95
Windows 98

Multi-user Operating System

Allows multiple users to access and use the same computer system simultaneously. The operating system manages resources fairly among different users while keeping each user's work isolated and secure.

Examples:
Linux
UNIX
Windows Server Editions
macOS Server

Multitasking Operating System

Allows a single user to run multiple applications or perform multiple tasks concurrently. The operating system rapidly switches between tasks, giving the illusion that all tasks are running simultaneously.

Examples:
Windows
macOS
Linux

Real-time Operating System (RTOS)

Designed for applications requiring precise and timely responses within strict deadlines.

Hard Real-time Systems:
Air traffic control systems
Medical life-support systems

Soft Real-time Systems:
Multimedia systems
Online gaming

Distributed Operating System

Manages a group of independent computers and makes them appear as a single coherent system, distributing tasks across multiple processors or computers connected through a network.

Examples:
Google's Fuchsia OS (in development)
Cluster computing systems

Introduction to UNIX

UNIX is a powerful, multi-user, multitasking operating system that originated in the 1960s at Bell Labs. It is known for stability, security, and portability, making it popular for servers, workstations, and high-end applications. Many modern operating systems, including macOS and Linux, derive their design principles from UNIX.

Introduction to Linux

Linux is an open-source, UNIX-like operating system kernel created by Linus Torvalds in 1991. Its source code is freely available, allowing anyone to run, study, modify, and redistribute it. This open-source nature has created a large community of developers contributing to its improvement.

Key Features of Linux

Open Source:
Free to use and modify.

Multi-user and Multitasking:
Supports multiple users and concurrent tasks.

Highly Secure:
Known for robust security features.

Stable:
Less prone to crashes.

Flexible:
Runs on hardware ranging from embedded systems to supercomputers.

Linux Distributions

A Linux distribution is an operating system built on top of the Linux kernel. It includes system utilities, libraries, development tools, and application software tailored for different purposes and users.

Common Linux Distributions

Ubuntu:
User-friendly distribution suitable for beginners.

Fedora:
Focuses on free and open-source software.

Debian:
Stable distribution that serves as the base for Ubuntu.

Mint:
Based on Ubuntu and Debian with a traditional desktop experience.

Red Hat Enterprise Linux (RHEL):
Commercial distribution for enterprise environments.

Kali Linux:
Specialized distribution for cybersecurity and penetration testing.

Types of Mobile Operating Systems

Mobile operating systems are specialized operating systems designed for smartphones, tablets, and smartwatches. They are optimized for touch-based interfaces, power efficiency, and wireless connectivity.

Android

Developed by Google, Android is the most widely used mobile operating system globally. It is based on the Linux kernel and allows manufacturers such as Samsung, Xiaomi, Oppo, Vivo, Realme, and OnePlus to customize it for their devices.

iOS

Developed by Apple Inc., iOS powers iPhones and iPads. It is known for its user-friendly interface, strong security features, and seamless integration with Apple's hardware and services.

Other Mobile Operating Systems

Windows Phone/Mobile:
Microsoft's discontinued mobile operating system.

BlackBerry OS:
Once popular for business users.

HarmonyOS:
Developed by Huawei as an alternative to Android.
