Chapter 2: Number System

Introduction to Number Systems

A number system is a systematic way of representing numbers. In computing, different number systems are used for various purposes, from internal processing to data representation.

The value of a digit in a positional number system depends on the digit itself, its position within the number, and the base (or radix) of the number system.

The main positional number systems are:

1. Decimal Number System (Base-10)

   - Uses 10 unique digits (0–9).
   - Each position represents a power of 10.
   - This is the number system used in daily life.


2. Binary Number System (Base-2)

   - Uses only two digits: 0 and 1.
   - Each position represents a power of 2.
   - It is the foundation of all digital computers.


3. Octal Number System (Base-8)

   - Uses eight digits (0–7).
   - Each position represents a power of 8.
   - Three binary digits can be represented by one octal digit.


4. Hexadecimal Number System (Base-16)

   - Uses digits 0–9 and letters A–F.
   - A = 10, B = 11, C = 12,
     D = 13, E = 14, F = 15.
   - Each position represents a power of 16.
   - Four binary digits can be represented by one hexadecimal digit.

The base or radix of a number system indicates the total number of unique digits or symbols used in that system.

Number System Conversions

Converting numbers between different bases is an important skill in computer science.

1. Decimal to Binary, Octal, and Hexadecimal Conversion

To convert a decimal number to another base, use the division-remainder method. 

Steps:
1. Divide the decimal number by the target base.
2. Write down the remainder.
3. Repeat until the quotient becomes zero.
4. Read the remainders from bottom to top.

2. Binary, Octal, and Hexadecimal to Decimal Conversion

Multiply each digit by its positional weight and add the results together. 

Formula:

Digit × (Base)^Position

Positions are counted from right to left,
starting from zero.

3. Binary to Octal and Hexadecimal Conversion

Binary to Octal:
- Group binary digits into sets of three.
- Add leading zeros if necessary.
- Convert each group into one octal digit.

Binary to Hexadecimal:
- Group binary digits into sets of four.
- Add leading zeros if necessary.
- Convert each group into one hexadecimal digit.

Introduction to Boolean Values, Truth Table, Boolean Expression, and Boolean Function

Boolean Algebra

Boolean Algebra, introduced by George Boole, is a branch of algebra where variables have only two possible values: True (1) and False (0). It forms the foundation of digital electronic circuits.

Boolean Values

True  = 1
False = 0

These represent the ON and OFF states
of electronic switches.

Truth Table

A truth table lists every possible combination of input values and the corresponding output for a logical operation or expression.

Boolean Expression

A Boolean expression combines Boolean variables, logical operators (AND, OR, NOT), and parentheses to produce a logical result. 

Example:
A + B'

Boolean Function

A Boolean function produces a binary output (0 or 1) based on binary inputs. It defines how the output of a logic circuit depends on its inputs.

Logic Gates

Logic gates are the basic building blocks of digital systems. They perform logical operations on one or more binary inputs and produce a binary output.

1. AND Gate

Output:
1 only when all inputs are 1.

Boolean Expression:
A · B

2. OR Gate

Output:
1 if at least one input is 1.

Boolean Expression:
A + B

3. NOT Gate (Inverter)

Output:
Reverses the input.

1 becomes 0
0 becomes 1

Boolean Expression:
A'

4. NAND Gate

Output:
0 only when all inputs are 1.

It is the opposite of the AND gate.

5. NOR Gate

Output:
1 only when all inputs are 0.

It is the opposite of the OR gate.

6. XOR Gate (Exclusive-OR)

Output:
1 when the two inputs are different.

Example:
0 XOR 1 = 1
1 XOR 0 = 1
1 XOR 1 = 0

7. XNOR Gate (Exclusive-NOR)

Output:
1 when the two inputs are the same.

Example:
0 XNOR 0 = 1
1 XNOR 1 = 1
1 XNOR 0 = 0
