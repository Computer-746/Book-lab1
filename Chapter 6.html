Chapter 6 Web Technology - I

Web Browsers and Search Engines

The internet is a vast network of computers, and to access the information available on it, we use specific software. These are primarily web browsers and search engines.

Web Browser

A web browser is an application software that allows users to access, retrieve, and view information and content on the World Wide Web (WWW). It acts as an interface between the user and the web server. When you type a website address (URL) or click a link, the browser sends a request to the web server, which then sends back the requested web page. The browser interprets the code (like HTML, CSS, JavaScript) and displays the content in a human-readable format.

Search Engine

A search engine is a web-based tool that enables users to locate information on the World Wide Web. Its main purpose is to search for information on the internet. Search engines are software programs that search for websites based on keywords typed in by the user. They go through their database of information to locate the information you are looking for.

How a Search Engine Works

Crawling:
   Search engine bots (also called spiders or crawlers) systematically browse the web, discovering new and updated web pages.

Indexing:
   The information gathered by crawlers is then processed and stored in a massive database, creating an index. This index is like a giant library catalog.

Searching:
   When a user enters a query, the search engine quickly searches its index for relevant pages and ranks them based on various algorithms to provide the most accurate results.

Overview of Internet and Web Technology

Internet

The Internet is a global system of interconnected computer networks that uses the Internet protocol suite (TCP/IP) to link billions of devices worldwide. It is a "network of networks" that consists of private, public, academic, business, and government networks of local to global scope, linked by a broad array of electronic, wireless, and optical networking technologies.

Key Concepts of the Internet

World Wide Web (WWW):
   A system of interconnected hypertext documents and other web resources accessed via the internet.

Client-Server Model:
   The internet primarily operates on a client-server model where a client requests information from a server.

Protocols:
   Rules that govern how data is transmitted over the internet.
   Examples include HTTP, HTTPS, FTP, and TCP/IP.

IP Address:
   A unique numerical label assigned to each device connected to a network.

Domain Name System (DNS):
   A system that translates human-readable domain names into IP addresses.

Web Technology

Web technology broadly refers to the tasks associated with developing websites for hosting via the internet or intranet. It encompasses the various tools, languages, and protocols used to create and maintain websites and web applications. This can range from developing static pages to complex web-based applications like e-commerce or social network websites.

Content Management System (CMS)

A Content Management System (CMS) is an application that allows users to create, manage, and modify content on a website without the need for specialized technical knowledge or coding skills. It simplifies the process of web content creation, workflow management, and publishing.

Key Features of a CMS

User-friendly Interface:
   Provides a graphical user interface with text editors similar to word processors.

Content Creation and Editing:
   Easily add, edit, and format text, images, videos, and other media.

Workflow Management:
   Allows multiple users to collaborate with different roles and permissions.

Design Templates:
   Offers pre-designed templates or themes.

SEO Tools:
   Built-in features to optimize website content for search engines.

Scalability:
   Can manage small personal blogs to large corporate websites.

Introduction to HTML (Objectives, Structure, Tags, Attributes)

HTML (Hypertext Markup Language)

HTML is the standard markup language for creating web pages. It provides the basic structure of a web page, defining its content and layout. Without HTML, the World Wide Web would not exist.

Objectives of HTML

To define the structure of web content.

To enable embedding text, images, multimedia, and other links or documents.

To provide a means to prepare a structured document by using paragraphs, formatting, links, and lists.

To allow web browsers to display the content of a web page.

To serve as the foundation upon which other web technologies like CSS and JavaScript are built.

HTML Attributes

Attributes provide additional information about HTML elements. They are specified in the opening tag and usually appear as name="value" pairs.

Attributes of the <a> Tag

   Specifies the destination URL.

   Specifies where the linked document opens.

   Specifies the image path.

   Provides alternative text.

Introduction to Cascading Style Sheets (CSS), Types and Uses

CSS (Cascading Style Sheets)

CSS is a stylesheet language used to describe the presentation of a document written in HTML or XML. It controls colors, fonts, layouts, and the overall appearance of web pages while keeping presentation separate from content.

Uses of CSS

Separation of Content and Presentation:
   HTML focuses on structure, while CSS focuses on styling.

Consistent Styling:
   Apply the same design across multiple web pages.

Faster Page Load Times:
   Browsers can cache external CSS files.

Responsive Design:
   Websites adapt to desktops, tablets, and mobile phones.

Richer User Experience:
   Supports animations, visual effects, and interactive elements.

Types of CSS

There are three main ways to implement CSS in an HTML document.

1. Inline CSS

Inline CSS applies a unique style to a single HTML element using the style attribute inside the opening tag. It is generally not recommended for large-scale styling because it mixes content with presentation.

2. Internal CSS (Embedded CSS)

Internal CSS defines styles for a single HTML page. The CSS rules are written inside a <style> tag placed within the <head> section.

3. External CSS

External CSS stores all style rules in a separate file with a .css extension. The HTML document links to this stylesheet using the <link> tag in the <head> section. This is the most efficient and recommended method for styling multi-page websites.

Example (styles.css file)

    font-family: Verdana, Geneva, sans-serif;

    color: #8a2be2;
